## macOS / Linux 命令

从解压后的 `FDEDeliveryWorkbench` 根目录开始，逐条执行；失败时停止后续步骤。

```bash
export FDE_REPO_ROOT="$PWD"
export DSH_CLIENT_COMMIT_HASH=337cd32a63a7042ccfd2ade412619ee41441f4c1
cd "$FDE_REPO_ROOT/upstream/deepseek-harness"
corepack pnpm install --frozen-lockfile
corepack pnpm run build
DSH_HOME="$FDE_REPO_ROOT/.runtime/dsh-home" \
  corepack pnpm dsh web --no-open --host 127.0.0.1 --port 3080
```

## Windows PowerShell 命令

先进入解压后的 `FDEDeliveryWorkbench` 根目录：

```powershell
$FdeRepoRoot = (Get-Location).Path
$env:DSH_CLIENT_COMMIT_HASH = '337cd32a63a7042ccfd2ade412619ee41441f4c1'
Set-Location (Join-Path $FdeRepoRoot 'upstream\deepseek-harness')
corepack pnpm install --frozen-lockfile
if ($LASTEXITCODE -ne 0) { throw '安装失败，停止。' }
corepack pnpm run build
if ($LASTEXITCODE -ne 0) { throw '构建失败，停止。' }
$env:DSH_HOME = Join-Path $FdeRepoRoot '.runtime\dsh-home'
corepack pnpm dsh web --no-open --host 127.0.0.1 --port 3080
```

访问 `http://127.0.0.1:3080`；在对应终端按 `Ctrl+C` 停止。后续重复启动时必须传入相同的 `DSH_HOME`，不要删除 `.runtime/`，其中将保存自己的会话和工作台数据。

## 详细手册的使用范围

`DEPLOYMENT_AGENT.md` 保留 Git 和完整交付版本的全部说明。本包采用其 **A 模式 + 无 .git 的 ZIP 路径**：跳过 B、示例导入、示例业务系统和缺失目录检查。C 模式仅在另行取得授权实验室素材后使用；Semantica 重运行也属于可选环境。
